# Система бронирования столов в ресторане

Учебный проект системного аналитика по проектированию системы бронирования столов в ресторане.

## О проекте

Система позволяет зарегистрированному пользователю выбрать ресторан, дату, время и количество гостей, после чего система проверяет наличие подходящего свободного стола и создаёт бронирование.

Пользователь также может просматривать и отменять свои бронирования.

## Цель проекта

Продемонстрировать процесс проектирования функциональности бронирования столов с точки зрения системного аналитика: от формирования требований до описания API, базы данных и архитектуры системы.

## Функциональность

- выбор ресторана;
- выбор даты и времени;
- указание количества гостей;
- проверка доступности столов;
- автоматический выбор подходящего стола;
- создание бронирования;
- просмотр бронирования;
- отмена бронирования.
